# Third-Party Content Notice

The files in this folder are working outputs from literature curation: spreadsheets, scripts, screening tables, and short extracted snippets with the DOI of the source article.

- Full-text PDFs of published articles are **not** redistributed in this repository. Open-access licenses differ between publishers and some files were preprints, so only the DOI, title, and curated fields are kept. To read an article, use its DOI.
- Short text snippets are included only to document where a curated value came from. Each is attributable to the DOI given in the same row. Copyright of the original text remains with its authors and publishers.
- If you reuse a snippet, cite the original article, not PesticideDB.
- If you are a rights holder and want an excerpt removed, contact the corresponding author listed in `CITATION.cff` / the paper.
