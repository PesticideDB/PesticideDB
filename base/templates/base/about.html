About PesticideDB

PesticideDB is a curated database and annotation platform for pesticide-degrading microorganisms, genes, proteins, and pathways. It currently contains curated information for {{ pesticide_count }} pesticides and {{ microorganisms_count }} pesticide-degrading microorganisms compiled from peer-reviewed scientific literature. Our mission is to improve access to microbial pesticide-degradation knowledge by integrating microorganisms, enzymes, genes, proteins, degradation pathways, annotation tools, and supporting experimental evidence in one searchable framework.

The database is updated every six months to keep up with new publications and add more pesticides.

If you have any information about microorganisms and proteins that we could use to improve the database, please submit a request to add, remove, or modify. You can also leave any comments in this form and we will get back to you.
