Upload a file

Please upload a FASTA file with genome, contig, scaffold, or predicted protein sequences. Nucleotide genome files will be translated into proteins before annotation. This tool searches genome proteins against PesticideDB reference proteins using DIAMOND and optionally confirms enzyme-family matches using HMMER.

BLAST type

Use BLASTP if your file contains protein sequences. Use BLASTX if your file contains nucleotide genome or contig sequences.

Organism type

This option can be used later for signal peptide prediction. If you do not use SignalP now, keep “No signal peptide prediction”.

E-value 1e-x


Expected number of chance matches in a random model. For example, 6 means 1e-6. Suggested values: 3 = loose, 6 = medium, 20 = strict.

Percent identity

Minimum percent identity of the alignments. Suggested values: 10 = loose, 30 = medium, 70 = strict.
