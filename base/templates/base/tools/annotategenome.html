Upload a file

Please upload a FASTA file with genome, contig, scaffold, or predicted protein sequences. Nucleotide genome files will be translated into proteins before annotation. This tool searches genome proteins against PesticideDB reference proteins using DIAMOND and optionally confirms enzyme-family matches using HMMER.

Interpretation: Genome hits identify candidate pesticide-degradation genes. They are not proof of degradation activity without experimental evidence.

Example: Test with a small JMP134 pathway FASTA containing cited pesticide-degradation proteins from Cupriavidus pinatubonensis JMP134. It is intentionally much smaller than a full genome so the demo runs quickly. Download example FASTA

Search mode

Auto mode detects protein versus nucleotide FASTA. For nucleotide input, it first predicts proteins with Prodigal and uses DIAMOND BLASTP; if no hits are found, it retries with DIAMOND BLASTX. HMMER is available when protein query sequences are available.

Search type

DIAMOND ranks all validated protein matches that pass your thresholds. HMMER adds enzyme-family support when the query is available as protein sequence.

Review E-value 1e-x


This value marks results that meet your preferred review criterion; it does not hide other detected alignments. For example, 5 means 1e-5.

Review identity

Used to mark results for review, not to remove them. Default 35% is a moderate genome-review criterion.

Review query coverage

Used to mark results for review, not to remove them. Default 30% keeps partial candidates visible; use 60-80% as a stricter full-length criterion.
