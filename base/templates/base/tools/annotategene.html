Please upload a FASTA file containing protein sequences or nucleotide sequences. DNA sequences will be translated into proteins using Prodigal before annotation. Short DNA fragments may not produce results. File names should contain only letters and numbers (A–Z, 0–9). Avoid spaces and special characters. This tool searches your sequence against PesticideDB reference proteins using DIAMOND and confirms enzyme-family assignment using HMMER.

Search type

DIAMOND identifies the closest known protein match. HMMER detects the broader enzyme-family profile.

E-value 1e-x


Expected number of chance matches in a random model. For example, 5 means 1e-5. Suggested values: 3 = loose, 5 = medium, 20 = strict.

Percent identity

Minimum DIAMOND percent identity. Suggested values: 30 = medium, 70 = strict.
