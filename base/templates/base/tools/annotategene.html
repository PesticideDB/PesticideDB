Upload a file

Please upload a FASTA file containing protein sequences or nucleotide sequences. DNA sequences will be translated into proteins using Prodigal before annotation. Short DNA fragments may not produce results. File names should contain only letters and numbers (A-Z, 0-9). Avoid spaces and special characters. This tool searches your sequence against validated PesticideDB reference proteins using DIAMOND. Protein queries also receive HMMER enzyme-family support; nucleotide gene queries are translated directly with DIAMOND BLASTX.

Interpretation: Results are candidate functional annotations based on sequence similarity and family profiles. They should not be treated as experimentally confirmed pesticide degradation unless the matched database record has supporting evidence.

Example: Test with tfdB / 2,4-dichlorophenol hydroxylase from Cupriavidus pinatubonensis JMP134, a cited PesticideDB protein record (PDBP0047, NCBI AAR31035.1). Download example FASTA

Search type

DIAMOND identifies and ranks all validated protein matches that pass your thresholds. HMMER detects the broader enzyme-family profile. Choose DIAMOND only when HMMER is unavailable on your server or when you need a faster preliminary search.

Review E-value 1e-x


This value does not hide results. It marks which reported alignments meet your preferred review criterion. For example, 3 means 1e-3. Suggested values: 3 = broad review, 5 = medium, 20 = strict.

Review identity

Used to mark results for review, not to remove them. Default 25% is broad discovery.

Review query coverage

Used to mark results for review, not to remove them. Default 30% keeps partial candidates visible; 60-80% is a stricter full-length criterion.
