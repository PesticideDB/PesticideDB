Global microbial distribution for pesticide-degrading microorganism species

The size of each circle indicates the number of pesticide-degrading microorganisms isolated from a given country. All isolates reported from the same country are grouped into a single circle positioned at the country’s center. The two largest circles correspond to China and India. Countries without red circles indicate regions where no published studies on pesticide-degrading isolates were found.

Isolation Environments

This analysis summarizes the environments from which pesticide-degrading microorganisms were isolated. The updated figure summarizes 833 reported microorganism records with pesticide-degrading capabilities. The category ‘Others’ includes isolates for which the source environment was not clearly specified, accounting for 11 records.

Trends in pesticide-degrading microbes and publications

This analysis summarizes the number of publications published each year that reported pesticide-degrading microorganisms, as well as the cumulative number of putative pesticide-degrading species identified from 1966 to 2026. When a microorganism already known to degrade pesticides was later shown to degrade an additional pesticide, this finding was counted as a new publication but was not included as a newly identified pesticide-degrading species.
